# ZX 远程控制方案（计划表）

> 目标：为 ZX 课程表插件配套一套局域网控制端，覆盖 Windows 与 Android。教师可在控制端远程修改课表、发送通知；ZX 插件所在的电脑作为被控端，负责展示与执行。

## 一、交付物

| 交付物 | 形态 | 位置 | 版本起点 |
| --- | --- | --- | --- |
| ZX 插件远程能力 | 主程序插件升级 | `plugins/zx.py`、`plugins/zx.json` | 1.3.0 |
| ZX 控制台（Windows） | 独立 PyQt6 桌面程序 | `zx_remote/` | 1.0.0 |
| ZX 控制台（Android） | 原生 APK，USB 安装 | `zx_remote_android/` | 1.0.0 |
| 协议与构建说明 | 本计划表 | `ZX_REMOTE_PLAN.md` | - |

主程序 `djs_pyqt6.py` 原则上不改动；远程能力全部由插件与两个控制端实现。若最终必须改动宿主，则按规则升主程序版本。

## 二、总体架构

```
┌──────────────────────────────┐           局域网            ┌───────────────────────────┐
│ 主程序 + ZX 插件（被控端）    │◄─────────────────────────►│ ZX 控制台（教师端）        │
│                              │   TCP + 长度前缀 JSON      │  Windows / Android        │
│ · 课程表悬浮窗 / 灵动岛       │                            │                           │
│ · 远程控制服务（配对、鉴权）  │       UDP 广播发现          │ · 发现设备 / 输入配对码    │
│ · 快速通知窗（置顶）          │◄─────────────────────────►│ · 课表查看与编辑           │
│ · 普通通知窗（可被遮挡）      │                            │ · 快速 / 普通通知          │
└──────────────────────────────┘                            └───────────────────────────┘
```

- ZX 插件是被控端兼服务端，负责生成配对码、确认配对、保存设备令牌、执行通知与课表变更。
- 控制端不保存权威课表，只做编辑与下发；权威数据始终在 ZX 插件所在电脑。
- 一台 ZX 可被多台设备配对；一台控制端可保存多个已配对主机。

## 三、端口与发现

| 用途 | 协议 | 端口 | 说明 |
| --- | --- | --- | --- |
| 现有局域网消息 | WebSocket | 48620 起 | 保持原样，不破坏 |
| 现有发现广播 | UDP | 48621–48632 | 保持原样 |
| 远程控制服务 | TCP | 48700 起顺延 | 被占用时自动+1，最多尝试 20 个 |
| 远程控制发现 | UDP | 48690 固定 | 多进程共享绑定，收到探测后单播回复实际控制端口 |

发现流程：控制端向 `255.255.255.255:48690` 与本网段广播地址发送探测包；ZX 回复设备名、设备 ID、控制端口、是否已配对。控制端同时支持手动输入 `IP:端口`，用于跨网段、AP 隔离或 USB 调试场景。

## 四、配对流程

1. ZX 设置页新增“远程”页签，点击“生成配对码”，得到 6 位数字码，有效期 5 分钟，显示本机 IP 与控制端口。
2. 控制端发现或手动连接 ZX，弹出配对对话框：设备名（可改）、配对码、[取消] [确认配对]。
3. 控制端发送配对请求；ZX 校验配对码。
4. ZX 弹出置顶确认框：显示设备名、平台、来源 IP，60 秒倒计时，[拒绝] [允许]。
5. ZX 允许后生成 32 位设备令牌并保存；控制端保存令牌，进入主界面。拒绝或超时则双方提示失败。
6. 之后连接使用“设备 ID + 令牌”鉴权，不再输入配对码；ZX 可在设备列表里随时移除设备。
7. 电脑对电脑：Windows 控制台走完全相同的流程。

约束：配对码一次性使用；同一 IP 连续失败 5 次锁定 60 秒；令牌只保存在本机配置中。

## 五、通知

| 类型 | 展示规则 | 默认时长 | 交互 |
| --- | --- | --- | --- |
| 快速通知 | 无边框、始终置顶于所有窗口之上、不抢焦点 | 8 秒 | 点击关闭；多条排队 |
| 普通通知 | 普通窗口，可被其他窗口遮挡 | 8 秒 | 点击关闭；多条排队 |

- 标题最长 60 字，正文最长 500 字，单设备每分钟最多 20 条。
- 两种通知都使用主程序深浅色调色板，带发送方设备名与类型标识。
- 通知由 ZX 自己绘制，不依赖灵动岛开关；灵动岛关闭时仍能收到远程通知。

## 六、课表同步

同步内容：多方案课程表、当前方案、节次时间、单双周模式、学期开始日期、课程与活动。

- 控制端拉取完整课表状态并编辑，保存时整包下发。
- 版本校验：ZX 对课表关键字段计算 12 位修订号。保存时携带起始修订号：
  - 一致：写入、保存、刷新悬浮窗与设置页，并推送新修订号给其他在线控制端。
  - 不一致：返回冲突与最新课表，控制端提示“电脑端课表已变化”，可选重新加载或覆盖。
- ZX 端校验：星期 1–7、节次范围、时间先后、周次取值、方案名非空、至少保留一个方案。
- 第一版可编辑：课程/活动的增删改、方案新建/重命名/删除/切换、节次时间增删改、学期开始日期、周次模式。
- 日覆盖（overrides）第一版只保留原值，不提供编辑。

## 七、通信协议

传输：TCP，4 字节大端长度 + UTF-8 JSON，单包上限 1 MB。

控制端 → ZX：

| 类型 | 关键字段 | 用途 |
| --- | --- | --- |
| `pair_request` | code、device{id,name,platform}、app_version | 申请配对 |
| `hello` | device_id、token、app_version | 已配对连接 |
| `ping` | ts | 心跳 |
| `notify` | mode(quick/normal)、title、body、duration | 发送通知 |
| `schedule_get` | - | 拉取课表 |
| `schedule_put` | base_rev、state、force | 保存课表 |
| `unpair` | device_id、token | 解除配对 |

ZX → 控制端：

| 类型 | 关键字段 | 用途 |
| --- | --- | --- |
| `pair_ok` | token、host{id,name,version}、rev、state | 配对成功 |
| `pair_reject` | reason | 配对失败 |
| `hello_ok` | host、rev、state | 鉴权成功 |
| `hello_fail` | reason | 令牌失效 |
| `pong` | ts | 心跳回复 |
| `notify_ok` | id | 通知已展示 |
| `schedule_state` | rev、state | 课表数据 |
| `schedule_saved` | rev | 保存成功 |
| `schedule_conflict` | rev、state | 版本冲突 |
| `schedule_changed` | rev | 其他端修改推送 |
| `error` | code、message | 通用错误 |

超时：连接 3 秒、普通请求 5 秒、配对确认 60 秒。

## 八、ZX 插件改动

1. 新增控制服务类：TCP 监听、UDP 发现、握手鉴权、协议分发、设备令牌管理、限流。
2. 数据保存：在插件配置中新增 `control` 节点，保存启用开关、设备列表、修订号；配对码只存内存。
3. 新增“远程”设置页：启用开关、生成配对码、配对码倒计时、本机地址、已配对设备列表与移除。
4. 新增配对确认框：置顶、60 秒倒计时、允许/拒绝。
5. 新增两个通知窗：快速（置顶）与普通（非置顶），深浅色适配，支持排队与自动关闭。
6. 课表接收：校验、写入、保存、刷新悬浮窗与设置页；广播修订号。
7. 现有局域网消息、课程表编辑、灵动岛、校时逻辑保持不变。

## 九、Windows 控制台

技术：Python 3.14 + PyQt6，独立进程，不依赖主程序运行。

目录：`zx_remote/`

| 文件 | 职责 |
| --- | --- |
| `main.py` | 入口、窗口装配、连接状态 |
| `theme.py` | 深浅色配色、QSS、圆角卡片 |
| `net.py` | 发现、TCP 客户端、协议编解码、自动重连 |
| `ui.py` | 连接页、配对对话框、课表页、通知页、设备页 |
| `version.py` | 对外版本与构建号 |

界面：

- 连接页：扫描到的 ZX 列表、手动地址、[扫描] [连接]、配对码对话框。
- 课表页：方案下拉、周网格（周一至周日 × 节次）、点击单元格编辑、节次设置、学期开始、周次模式、[刷新] [保存到 ZX]、未保存提示。
- 通知页：标题、正文、快速/普通选择、时长、[发送]、最近发送记录。
- 设备页：主机信息、连接状态、[重新连接] [解除配对]、主题（跟随系统/深色/浅色）、版本信息。
- 配色与主程序一致：深色 `#12141C / #1A1D27 / #232634 / #FBBF24`，浅色对应主程序浅色调色板；全部界面同时支持深浅色。

配置：`%APPDATA%\ZXRemote\config.json` 保存设备 ID、令牌、最近主机、主题与窗口位置。

## 十、Android 控制台

技术：原生 Java，单 Activity + 代码布局，不引入 AndroidX，减少构建依赖。

目录：`zx_remote_android/`

| 路径 | 职责 |
| --- | --- |
| `app/src/main/AndroidManifest.xml` | 权限、主题、入口 |
| `app/src/main/java/com/miaoruixuan/zxremote/MainActivity.java` | 页面与交互 |
| `.../Protocol.java` | TCP、发现、协议、后台线程 |
| `.../Store.java` | SharedPreferences 配置 |
| `res/` | 图标、颜色、字符串、主题 |
| `build.ps1` | aapt2 + javac + d8 + zipalign + apksigner 一键构建 |

界面：

- 连接页：扫描到的 ZX 列表、手动地址、配对码输入、设备名。
- 主页底部导航：课表 / 通知 / 设置。
- 课表：方案选择、星期切换、节次列表卡片；点击编辑课程名/教室/周次，支持活动时间；长按删除；[保存]。
- 通知：标题、正文、快速/普通选择、时长、[发送]、历史记录。
- 设置：主机信息、解除配对、主题（跟随系统/深色/浅色）、版本信息。
- 深浅色同时适配，配色与主程序一致。

权限：`INTERNET`、`ACCESS_NETWORK_STATE`、`ACCESS_WIFI_STATE`。最低 Android 7.0（API 24），目标 API 35。

构建与安装：

1. 使用 JDK 21（避免 JDK 26 与 Android 构建工具不兼容）。
2. 使用 `aapt2` 编译资源、`javac` 编译、`d8` 生成 dex、`zipalign` 对齐、`apksigner` 签名。
3. `adb install -r` 安装到手机。
4. 真机联调优先走同一 Wi-Fi；若路由器隔离或跨网段，用 `adb reverse` + 手动地址 `127.0.0.1` 测试。

## 十五、风险与处理

| 风险 | 处理 |
| --- | --- |
| Windows 防火墙拦截新端口 | 同一程序已有放行规则时通常自动通过；若被拦截，提示用户在防火墙弹窗中允许 |
